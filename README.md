# 週末ふたり旅 V13 — 宿カードテンプレート化

この版では、今後の宿追加は基本的に `stays.json` に1件追記するだけで、
同じデザインのカードが自動生成されます。

## 追加手順
1. リール動画から横長のカード画像を1枚作り、同じフォルダへ保存
2. `stay-template.json` を参考に、`stays.json` の配列へ1件追加
3. 楽天アフィリエイトURLがある場合
   - `rakuten_url` にURL
   - `rakuten_enabled` を `true`
4. じゃらんA8商品リンクがある場合
   - `jalan_url` にA8リンク
   - `jalan_enabled` を `true`
   - A8の1x1計測URLがある場合は `jalan_tracking_pixel` に設定
5. アフィリエイト不可の予約サイトはURLを空欄、`enabled` を `false`
   → ボタンが薄暗くなり、クリック不可になります。
6. リール未作成の場合
   - `reel_url` を空欄
   - `reel_enabled` を `false`

## カード表示ルール
- 宿名：最大2行
- 説明文：最大3行
- 写真：16:9
- ボタン：リール / 楽天 / じゃらん
- 予約導線が両方ない宿はカード全体を少し落ち着いた表示にします。
- `featured: true` の宿には「今週のおすすめ」を表示します。
- ラベルを個別指定したい場合は `recommend_label` に文言を設定します。

## 重要
`stay-template.json` は説明用で、サイト本体からは読み込まれません。
実際に表示される宿は `stays.json` に入っているものだけです。


## 掲載対象の必須条件
`rakuten_available` または `jalan_available` の最低どちらか1つが `true` の宿だけ表示されます。

- 楽天あり / じゃらんあり → 掲載
- 楽天あり / じゃらんなし → 掲載
- 楽天なし / じゃらんあり → 掲載
- 楽天なし / じゃらんなし → 自動除外

「available」は予約サイトに宿が掲載されているか、
「enabled」はアフィリエイトリンクを実際に有効化済みか、を分けて管理します。
